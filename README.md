# website

Landing site for [www.meraxislabs.com](https://www.meraxislabs.com).

Static HTML/CSS/JS. Contact currently uses `mailto:hello@meraxislabs.com` (form opens the user’s email app). A custom backend can replace this later.

## Search Console

1. Open [Google Search Console](https://search.google.com/search-console) and add `https://www.meraxislabs.com`.
2. Verify ownership (HTML tag or DNS).
3. Sitemaps → submit `https://www.meraxislabs.com/sitemap.xml`.
